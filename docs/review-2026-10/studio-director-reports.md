# Studio Director's reports, and what replaces each one

Hannah's Studio Director account lists these reports (from Stephen's screenshots, October 19). She asked for "all existing report functionality". Each row says where it lives on the new site and in which phase. Every report downloads as a spreadsheet.

**Phases:**
- **1** = by launch (mid-November).
- **2** = by the first spring class.
- **Later** = after spring starts, if wanted.
- **Not needed** = Little Characters doesn't do this, with the reason.
